# 04 验收门禁与交付

## 门禁 0：输入正确
- [ ] 源图标题、主要模块名称、页数、图层与 `manifest.json` 相符。
- [ ] 未调用无关旧项目内容；若改母版则使用指定最新版。

## 门禁 1：视觉完整
- [ ] 独立裁剪图块对照原图：节点、趋势图数据点、图例、雷达/网络边缘均完整。
- [ ] 没有非等比例拉伸、裁切损伤、重叠的旧文字、异常白边。
- [ ] 分区和模块位置/规模接近原图，未改变技术归属。

## 门禁 2：可编辑性
- [ ] 文字、框、连接线均为原生对象；同一列表一个文本框。
- [ ] 图片是可独立选择/移动的独立对象，而不是整页 PPT 截图。

## 门禁 3：技术逻辑
- [ ] 箭头方向正确，主干分支与合流完整，没有错连/漏连、文字遮挡。
- [ ] 关键原始文本准确，无擅自增删术语或补写。

## 门禁 4：自动检测
运行：
```sh
python scripts/validate_pptx.py output.pptx --manifest manifest.json --json-report qa.json
```
- 图片可见宽高比相对误差不得超过 1%；对象不得越过页边界。
- 标题与必含技术术语必须能在原生文字文本框中搜索到（原图上属于图片内部的文字除外）。
- 图片数量与可编辑文本框数量可供验收，但不能单凭数量保证可编辑性。
- 自动检测返回非 0 不得直接交付；审查后修复或明确说明未知限制。

## 门禁 5：真实渲染 + 对照
1. 使用 pptx 渲染工具（例如 LibreOffice/PowerPoint 兼容导出）生成逐页 PNG。
2. 运行 `scripts/compare_preview.py --source source.png --preview rendered.png --output compare.png`。
3. 按原图对照：图片底部节点、全部图例、标题清晰度、模块位置、流向、白底、布局溢出。
4. 仅在肉眼比对后写“已检查实际预览”；没有检查不能承诺完全通过。

## 交付
- 用户可打开的 PPTX 沙箱链接。
- 同页 PNG 预览图（多页则每页或合集）。
- 一段简要说明：从哪张图做的、多少页、哪些可编辑、哪些专业图在截图内不可编辑、比例是否通过、已知限制。
- QA 异常不能隐藏；不要以“高保真”声称已消除一切差异。
